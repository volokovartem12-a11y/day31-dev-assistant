# День 31. Ассистент разработчика

Ассистент отвечает на вопросы о проекте. Он знает документацию (README, папку `docs/`, схемы и API) через RAG,
получает git-ветку и список файлов через MCP-сервер и отвечает в чате по команде `/help`.

Модель для ответов: **AITunnel, gpt-5.6-luna**. Ключ вводится скрытым вводом и в файлы не сохраняется.

## Состав

| Файл | Что делает |
|---|---|
| `assistant.py` | Чат, команды `/help`, `/branch`, `/files`, `/reindex`, режим `--once` |
| `mcp_server.py` | MCP-сервер (stdio, JSON-RPC): инструменты `git_branch`, `list_files`, `git_diff` |
| `mcp_client.py` | MCP-клиент: запускает сервер и вызывает инструменты |
| `project_docs.py` | Сбор документации проекта и сборка индекса |
| `chunking.py`, `loaders.py`, `embeddings.py`, `index_store.py` | RAG-модули из дней 21–28 |
| `local_llm.py` | Локальная модель Ollama (вариант `--llm ollama`) |
| `test_day31.py` | Проверки ТЗ на имитации (без интернета и без ключа) |
| `run.ps1` | Запуск для Windows: чат, индекс, тесты |
| `docs/` | Документация проекта — её индексирует ассистент |

## Запуск

```
.\run.ps1                                  # чат о самом проекте ассистента
.\run.ps1 -Project "путь\к\проекту"        # чат о другом проекте
.\run.ps1 -Mode test                       # проверки на имитации
```

Команды в чате: `/help <вопрос>`, `/branch`, `/files [папка]`, `/reindex`, `/exit`.

## Требования

- Windows 10/11, Python 3.10+ (`py` или `python`).
- Пакет `numpy` (ставится автоматически при первом запуске `run.ps1`).
- Для ответов через AITunnel — ключ. Для `--llm ollama` — Ollama с моделью на этом ПК.
- Для ветки и diff — git. Без git ассистент работает, но `git_branch` сообщит, что папка не репозиторий.

## Что проверено

На имитации (в песочнице, без интернета): протокол MCP, инструменты в git-репозитории и без него,
защита от выхода за папку проекта, индекс документации, `/help` с имитацией AITunnel (проверяется
заголовок авторизации и модель gpt-5.6-luna), сквозной запуск `--once`.

Только на ПК пользователя: запуск с настоящим AITunnel и ключом, работа с реальным репозиторием,
`--llm ollama`, `--embed ollama`.

## Ограничения

- MCP реализован на стандартной библиотеке, без официального SDK (PyPI в песочнице недоступен).
  Протокол соответствует версии `2024-11-05`, но совместимость с другими клиентами не проверялась.
- Лексические эмбеддинги `local` ищут совпадения слов, не синонимы.
- Индекс не обновляется сам: после правок документов выполните `/reindex`.
