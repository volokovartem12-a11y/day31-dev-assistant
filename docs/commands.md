# Команды ассистента

## В чате

- `/help <вопрос>` — ответ о проекте с контекстом: документация, git-ветка и список файлов.
  Пример: `/help какая структура проекта`. Это основная команда дня 31.
- `/help` без вопроса — показывает список команд.
- `/branch` — текущая git-ветка. Получается через MCP-инструмент `git_branch`.
- `/files` — список файлов проекта. С параметром: `/files docs` покажет только папку docs.
- `/reindex` — пересобрать индекс документации после правок.
- `/exit` — выход.
- Любой текст без слеша — вопрос только по документации, без списка файлов.

## Из командной строки

- `python assistant.py --project <папка>` — чат о проекте.
- `python assistant.py --project <папка> --once "/help как запустить проект"` — один ответ и выход.
- `python assistant.py --project <папка> --build` — только собрать индекс.
- `--llm ollama --model qwen2.5:7b` — отвечать локальной моделью вместо AITunnel.
- `--embed ollama` — семантические эмбеддинги bge-m3 вместо лексических.

## Через run.ps1

- `.\run.ps1` — чат о самом проекте ассистента.
- `.\run.ps1 -Project "путь"` — чат о другом проекте.
- `.\run.ps1 -Mode index -Project "путь"` — только индекс.
- `.\run.ps1 -Mode test` — проверки ТЗ на имитации. Ключ и интернет не нужны.

## Ключ AITunnel

Ключ спрашивается скрытым вводом, если переменная `AITUNNEL_API_KEY` не задана.
В командах и файлах ключ не указывается.
